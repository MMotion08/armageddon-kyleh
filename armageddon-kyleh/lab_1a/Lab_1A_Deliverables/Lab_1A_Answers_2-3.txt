2) Short answers:
 
A) Why is DB inbound source restricted to the EC2 security group? 
Because you only want a particular application to talk to the database, not give access to other applications. It makes it scalable and works with automation, enforces least privilege,  adds depth in defense and prevents over-exposure.

B) What port does MySQL use? 
Port 3306

C) Why is Secrets Manager better than storing creds in code/user-data?
Code and user scripts are not secret – anyone that has access can read your source code without any security challenges
Secrets Manager uses IAM for access control, supports rotation without redeployment, secrets will not appear in Terraform, enables least privilege,

Then Answer: 
Why each rule exists?
What would break if removed? 
Why broader access is forbidden?
Broader access forbidden because the idea is to restrict access to only instances that have the role attached to it  
Why this role exists 
Why it can read this secret? 
This IAM role has the inline policy that provides permissions to read the DB secret info for one specific DB secret in the manager.  
Why it cannot read others? 
The inline policy that provides permissions to read the DB secret info for one specific DB secret in the manager restricts it to only reading that particular one.
